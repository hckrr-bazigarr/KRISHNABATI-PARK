# KRISHNABATI ULIR PARK (INTERNATIONAL)

A responsive website project for KRISHNABATI ULIR PARK (INTERNATIONAL).

## Features

- Responsive homepage
- About page
- Google Maps location embed
- Gallery page with Google Maps listing link
- Visitor booking form prototype
- My Booking demo page
- Admin interface prototypes
- Express.js API starter
- PostgreSQL database schema
